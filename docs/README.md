# Documentación — CineWeb Frontend

Punto de entrada de la documentación del frontend, con lo que pide la cátedra para la entrega de
regularidad (`docs.md` del TP). El backend tiene su propia documentación en
[TP-BackEnd](https://github.com/EduardoMarino73/TP-BackEnd).

## Regularidad

| Contenido | Dónde está | Estado |
|---|---|---|
| Propuesta actualizada | [proposal.md en el fork del TP](https://github.com/liamlucca/tp-web-de-peliculas/blob/main/proposal.md) | ✅ |
| Links a los PR | [Pull requests](#pull-requests) (abajo) | ⏳ Pendiente |
| Instrucciones de instalación | [README del proyecto → Puesta en marcha rápida](../README.md#puesta-en-marcha-rápida) | ✅ |
| Minutas de reunión y avance | [Registro de avance](avance.md) (armado a partir de git) y [minutas](minutas/README.md) | 🟡 Faltan las minutas |
| Tracking de features, bugs e issues | [tracking.md](tracking.md) | 🟡 Falta el tablero |

`avance.md`, `tracking.md` y `minutas/` son del equipo: están copiados igual en el backend.
